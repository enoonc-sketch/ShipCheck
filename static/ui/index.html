            ShipCheck Settings
            
      
            Settings are stored in Forge Storage. Your API key is stored there too
        and is never shown back after saving.
            
      
            Releases
            
      
            One row per release (project + version). The dashboard scores the
        release you pick there; the digest runs for every row with the
        weekly digest switched on.
            
      
            
      
            
        
      
            
      
      
            
        Scoring weights
        
            
          
          
          
          
          Total: 100
        
            
        The four weights must add up to 100. The defaults are 40 / 25 / 20 / 15.
      
            
      
            
        CoArena API key
        
        Enables the optional AI summary on the dashboard. Leave blank to keep the saved key.
        
            
      
            
      
            
        
      
            
      
            
        Bitbucket API token
        
        Read-only API token for pull requests and pipelines. One token for all
          releases above — it must have read access to every repository listed.
          Used only to read them — never shown back after saving.
        
            
      
            
      
            
        Slack webhook URL
        
        Posts a short alert to a Slack channel when the verdict drops to BLOCKED or a new blocker appears — the same trigger as the Jira comments below. Leave blank if not used; never shown back after saving.
        
            
      
            
      
            
        
      
            
      
            
        
      
            
      
            
        Digest day
        
      
            
      
            
        
        
      
            
    
            
    
            
      
            Weekly digest
            
      
            The digest is a scheduled trigger that runs once a day. It only sends
        on the weekday chosen above (default Friday) and at most once a week.
        The trigger only runs on a real site — it cannot be tested locally.
            
      
            
      
            
        
        
        
      
            
      “Run digest now” sends the report immediately but does not change
        the weekly schedule — the next scheduled digest still fires on its day.
